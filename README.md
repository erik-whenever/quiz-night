# Kronan 👑

Veckans quiz för gänget. Erik är host, alla andra buzzar från mobilen medan ni pratar i Discord. Varje vecka kröns en kung.

**Spela:** gå in på appen, skriv rumskoden och tryck på den röda knappen när du kan svaret. Du har några sekunder på dig att säga svaret. Fel eller för sent kostar poäng.

**Hosta:** `/host` → välj frågeset → öppna rum. Skärmdela TV-vyn i Discord och styr från hostkontrollen (R = rätt, F = fel, V = visa svar, N = nästa).

Appen byggs vidare varje dag av ett AI-råd. Se [`council/`](council/README.md). Har rådet frågor till Erik ligger de i [`council/BEHOVER-ERIK.md`](council/BEHOVER-ERIK.md).

Teknik och kommandon: [`CLAUDE.md`](CLAUDE.md).
