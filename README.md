# Kronan 👑

Veckans quiz för gänget. Erik är host (och kan spela med utan facit), alla svarar med alternativ i mobilen medan ni pratar i Discord. Varje vecka kröns en kung.

**Spela:** gå in på appen, skriv rumskoden och ditt namn (samma varje vecka). Välj alternativ i mobilen; ett tryck låser. Snabbaste rätt får bonus, fel kostar inget.

**Hosta:** `/host` → välj frågeset, antal alternativ och om du spelar själv → öppna rum. Skärmdela TV-vyn i Discord och styr från hostkontrollen (V = visa svaret, N = nästa fråga). Spelar du själv ser hostkontrollen inget facit.

Appen byggs vidare varje dag av ett AI-råd. Se [`council/`](council/README.md). Har rådet frågor till Erik ligger de i [`council/BEHOVER-ERIK.md`](council/BEHOVER-ERIK.md).

Teknik och kommandon: [`CLAUDE.md`](CLAUDE.md).
